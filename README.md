# Программа учёта и анализа личных финансов

Проект персонального рублёвого журнала. Владелец ведёт операции по категориям и сверяет остаток на конец месяца. В истории сохранён исходный каркас первой рейтинговой работы. Материалы второй работы включают модель учёта на SQLite и прототип интерфейса с демонстрационными данными.

## Как проверить расчёт

Нужен Python 3.12 со стандартным модулем sqlite3. Команды выполняются из корня репозитория.

```console
python -m src.main
python -m unittest discover -s tests -v
python -m tests.benchmark
```

Для ноябрьского примера программа выводит в копейках доход 3 000 000, расход 140 000 и остаток 3 860 000. Операция на 60 000 копеек сохраняется черновиком. Команда запуска создаёт временную базу в памяти. Описание ограничений и сценариев находится в [документации по проектированию](docs/design.md).
