# Иерархическая структура работ

**Иерархическая структура работ из РР1**

| Этап | Состав работ | Результат и ветка |
| --- | --- | --- |
| 1. Инициация | Определить тему, цель и границы | Описание идеи в README.md · main |
| 2. Анализ требований | Собрать и описать требования | docs/requirements.md · feature/requirements |
| 3. Проектирование | Описать данные, модули и интерфейс | docs/design.md или README.md · feature/design |
| 4. Разработка | Создать основные файлы программы | src/main.py, src/models.py, src/reports.py · feature/income-expenses |
| 5. Отчёты и аналитика | Рассчитать баланс и расходы по категориям | Модуль отчётов · feature/reports |
| 6. Тестирование | Проверить базовые сценарии | Тесты в tests · feature/testing |
| 7. Внедрение | Подготовить первую стабильную версию | Версия v1.0 · release/v1.0 |
| 8. Сопровождение | Исправлять ошибки и дорабатывать функции | Новые коммиты и версии · hotfix/*, develop |

Ветки обозначают исходный план работ. Фактические ветки и версии доступны в Git.
